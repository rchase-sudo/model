Preliminary Site Design

Sell the land by showing what it can become.

Forma turns a vacant land listing into a preliminary site plan, a 3D rendering and a due diligence package. Agents use it to market the parcel and answer a buyer's first questions.

01 Read the ground

Topography from LiDAR.

This is a real Forma job: 1.32 acres on NJ Route 73 in Voorhees Township. Every package starts from public LiDAR elevation data and the county parcel record. The point cloud becomes contours, so slope, high ground and low spots show up before anyone walks the site.

Source
Public LiDAR and parcel data
Survey
Not required. If the seller has one, we use it.

02 Draw the lines

Boundary, setbacks, envelope.

Property lines come from the parcel record. Setbacks come from the local zoning code. What's left between them is the buildable envelope, and the concept has to fit inside it.

03 Fit the program

A layout a buyer can believe.

Buildings, parking, access and landscaping go in at real dimensions, using the uses the zoning allows. On this parcel that's a 5,900 SF bank with drive-thru, a loop drive off one curb cut and 25 spaces.

05 Same layout, in 3D

Then we render it.

The rendering is built from the plan, so the building, the drive loop and every parking stall sit where the plan puts them. Buyers see a finished project in its real setting, from the road to the tree line.

07 Inside the package

Eleven pages a buyer's analyst can use.

The Route 73 package answers the first questions a developer asks. What can go here, what it takes to permit, what it costs to build, and what the land is worth under each way to sell it. At the $600K asking price, all three exits modeled show positive value.
